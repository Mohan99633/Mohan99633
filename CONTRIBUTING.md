# Contributing Guidelines

Thank you for your interest in contributing to my GitHub profile repository!

## How to Contribute

This repository serves as my personal GitHub profile. While pull requests for fixing typos, broken links, or improving accessibility are highly appreciated, major content changes will be handled personally.

If you spot an issue, feel free to open an issue or a PR!

## Development & Customization

If you'd like to use this profile as a template for your own:

1. Fork this repository.
2. Update the `README.md` with your information.
3. Replace assets in `assets/` with your own (banners, icons, etc.).
4. Update the `.github/workflows/` with your GitHub username if necessary.
5. Refer to `docs/customization.md` for detailed instructions on customizing the repository.

### Code Style
- Keep Markdown semantic and clean.
- Ensure all SVG and image assets are compressed and accessible (include alt text).
- Avoid unnecessary HTML where Markdown suffices, but use HTML for specific layouts (like tables/cards).

### Reporting Bugs
Please use the GitHub Issue Tracker to report any bugs or broken links.

Thank you!
